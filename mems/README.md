# Meme images

Add your meme images to this folder. The current `script.js` expects these filenames:

- `meme1.jpg`
- `meme2.jpg`
- `meme3.jpg`
- `meme4.png`
- `meme5.gif`

You can use different filenames, but update the `memes` array in `script.js` to match them exactly. GitHub Pages paths are case-sensitive. Supported browser image formats include JPG, PNG, GIF, and WebP.
